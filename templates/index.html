Platform Features

A complete security analytics pipeline — from data ingestion to explainable threat intelligence.

AI Threat Detection
Random Forest classifier trained on UNSW-NB15 labels identifies suspicious and malicious network flows.
Anomaly Detection
Isolation Forest detects behaviorally unusual events beyond known attack signatures.
Security Alerts
Auto-generated alerts with severity levels, analyst notes, status tracking, and filtering.
Explainable AI (XAI)
SHAP-powered per-event explanations show which features drove each prediction.
Real-Time Simulation
Replay events sequentially from any uploaded dataset with live ML inference and charts.
PDF & CSV Reports
Downloadable security reports with full analysis summaries, metrics, and event data exports.

How It Works

A structured pipeline from dataset upload to actionable threat intelligence.

1
Upload Dataset
Upload a UNSW-NB15 compatible CSV. Schema is validated automatically.
2
ML Analysis
Random Forest classifies each event; Isolation Forest scores behavioral anomalies.
3
Risk Scoring
Composite risk score is computed combining threat probability and anomaly score.
4
Alerts & XAI
Alerts auto-generate; SHAP explains each detection with feature attributions.
5
Reports
Export PDF reports and CSV event data for documentation and review.
